# Таблица соответствия требованиям

Документ отвечает на один вопрос: **что именно из требований выполнено и чем это подтверждено**.
Он обновляется при каждом изменении поведения.

## Статусы

| Статус | Значение |
| --- | --- |
| **Не реализована** | Функции нет в коде. |
| **Реализована частично** | Есть часть поведения; чего именно не хватает — написано в колонке «Остаётся». |
| **Реализована, но не проверена** | Код есть, автоматической проверки нет. |
| **Проверена автоматически** | Есть тест, который выполняется командой и проходит. |
| **Проверена вручную** | Проверено человеком (запуск, чтение кода, ручной сценарий), без автотеста. |
| **Не проверена** | Внешняя проверка (аудит зависимостей, пентест) не проводилась. |
| **Требует решения владельца** | Нельзя решить без выбора владельца: варианты различаются по смыслу продукта, рискам или стоимости. |

Сводка по 88 требованиям таблицы (статус проверки берётся из столбца «Как проверено»):

- **Проверена автоматически — 64** (в том числе 4 требования дополнительно проверены вручную).
- **Проверена вручную, без автотеста — 21.**
- **Не проверена — 2** (5.7: периодическая уборка устаревших состояний; 8.15: аудит зависимостей и
  пентест сторонними средствами).
- **Не реализована — 1** (2.8: друзья и контакты — следующий этап).
- **Отложено осознанно (по замыслу не реализовано) — 4** (10.1 медиа, 10.2 монетизация,
  10.5 нагрузочные испытания, 10.7 мониторинг).
- **Реализована частично — 1** (6.8: два режима доступности из трёх).
- **Требует решения владельца — 0.** Три прежних открытых вопроса закрыты 2026-10-19: возрастных
  ограничений нет (3.7; `DECISIONS.md` D20), архивы сделаны и доступны только владельцу (8.14;
  `DECISIONS.md` D21), и решено, как владелец входит в архив — ключ `ADMIN_TOKEN` из файла настроек и
  страница `/admin`. Остаются инженерные долги, а не решения владельца: шифрование архива и аудит
  действий владельца (`SECURITY.md` §13–14).
